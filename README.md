# Klätterverket Academy

Digital utbildningsplattform för personalen på Klätterverket Gasverket och Sickla.

- **Webbplatsen** publiceras automatiskt på GitHub Pages vid varje uppladdning.
- **Nya utbildningar** läggs som egna mappar under `utbildningar/` — se `utbildningar/LÄS.md`.
- **ChatGPT-instruktionen** för att skriva nya utbildningar finns i `ChatGPT-instruktion/`.
- **Allt om uppsättning och drift** står i `LÄSMIG.html` (öppna den i webbläsaren).
